# Desafio 3 – Android

**Projeto:** Sincronização em Segundo Plano com Notificações

## Descrição
Aplicativo Android desenvolvido em Kotlin que simula um processo de sincronização em segundo plano, atualizando uma notificação fixa a cada 5 segundos com a quantidade de pacotes processados.

## Funcionalidades
- Iniciar o serviço de sincronização.
- Processar pacotes de forma simulada.
- Atualizar a notificação a cada 5 segundos.
- Exibir a quantidade de pacotes processados.
- Interromper o serviço pelo botão Parar.

## Tecnologias utilizadas
- Kotlin
- Android Studio
- Android Services
- Notificações Android
- Coroutines

## Execução
Baixe o arquivo ZIP do projeto, extraia-o e abra a pasta no Android Studio.

## Observação
O processamento é simulado e não realiza envio real de dados para um servidor.
